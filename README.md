# CodeAlpha_FlashcardQuizApp

An Android Flashcard Quiz Application developed as part of the CodeAlpha Android Development Internship.

## Features
- **Flashcard Display:** Interactive flashcards with question and hidden answer state.
- **Answer Reveal:** Toggle answer visibility on demand.
- **Bi-directional Navigation:** Move back and forth across cards using Next and Previous controls.
- **Card Management (CRUD):** Add custom cards, edit active card text, or delete cards dynamically.

## Tech Stack
- **Language:** Java
- **UI:** Android XML / Material Components / CardView
- **IDE:** Android Studio
